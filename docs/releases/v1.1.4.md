# 邻传 Nearby Transfer v1.1.4

## 更新说明

- Android 原生端重新整理连接、发送、聊天、设置四个页面的排版与间距，统一输入框、按钮、底部导航和深色视觉层级。
- 修复 Android 聊天消息、长文本、长文件名和多行输入内容显示不完整的问题，支持自动换行与输入框自适应高度。
- 优化 Android 群聊新建与加入弹窗，修复输入框被压扁、贴边的问题。
- 修复电脑端接收 Android 直聊消息时，旧版本遗留的“我的手机：”设备名前缀显示问题；历史消息和复制内容也兼容清理。
- 群聊继续保留独立的发送者名称显示，便于成员识别。

## 发布文件

- Windows x64 NSIS 安装包
- Microsoft Store MSIXUPLOAD 提交包
- Android 正式签名 APK

## 验证

- 协议、端到端、群聊测试全部通过。
- Android 原生项目 Gradle 构建通过。
- Windows 安装包和 MSIXUPLOAD 产物完成校验后发布。
