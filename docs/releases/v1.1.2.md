# 邻传 Nearby Transfer v1.1.2

## 更新说明

- 新增聊天消息、收到文件请求及传输完成/失败提示音；桌面端与 Android 端均支持。
- 修复 Windows 桌面端拖拽文件时无法读取文件路径的问题，发送区和聊天区均可拖入文件。
- 优化通知与提示音的配合，避免前台重复响铃；Android 文件通知使用静音通知通道。

## 下载

- Windows Setup：Windows x64 安装包；未使用公开信任的 Windows 代码签名证书，Windows 可能显示 SmartScreen 提示。
- Android APK：正式签名版本。
- MSIXUPLOAD：供 Microsoft Partner Center 提交；此文件不代表应用已在 Microsoft Store 上架。
