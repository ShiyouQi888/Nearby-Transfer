# 邻传 Nearby Transfer v1.0.0

局域网内 **Windows ⇄ Android** 互传文件，**不经过任何外网服务器**。

## 下载

| 平台 | 文件 | 说明 |
|---|---|---|
| Windows 10/11 x64 | `Nearby-Transfer-Setup-1.0.0.exe` | NSIS 安装包，可选安装目录 + 桌面快捷方式 |
| Android 6.0+ (API 22+) | `Nearby-Transfer-v1.0.0-debug.apk` | 调试签名版，安装时需允许「未知来源」 |

## 功能

- **设备发现** — UDP 组播 `239.255.42.99` 自动发现在线设备（名称 / IP / 类型）；也可手动扫描指定网段并发探测
- **配对连接** — 手机扫二维码建立连接（5 分钟临时令牌）；或输入 6 位匹配码；配对成功写入「已信任设备」，之后免配直连
- **文件传输** — 双向发送图片 / 视频 / 文档 / 文件夹 / 批量文件；实时进度、速度、剩余时间与传输历史；大文件 256KB 分片、断点续传（`.lpart`）、中途取消
- **安全与交互** — 接收方确认后才接收并展示发送方设备名；未配对设备一律拒绝；接收路径强制清洗杜绝 `../` 穿越；数据全程仅走局域网

## 界面

- 翡翠绿设计系统，统一内联 SVG 图标（电脑端 53 个，无 emoji）
- **无边框窗口 + 自绘标题栏**，关闭 / 最小化 / 最大化还原完全融入品牌配色
- 内嵌**思源黑体可变字重子集**（源字体 16.9 MB → 1.0 MB，保留 100–900 完整字重轴），正文基准 450 字重
- 侧栏「关于」页 + 设置弹窗「关于」页签双入口：运行环境、邮箱 / 官网 / 微信公众号、版权与字体授权说明（思源黑体 SIL OFL 1.1）

## 技术栈

| 端 | 组成 |
|---|---|
| 电脑端 | Electron 33 · 原生 `net`/`dgram` · 手写 WebSocket 网关 · electron-builder（NSIS） |
| 手机端 | Capacitor 6 · Vite 5 · 原生 TCP（`NativeClient`）优先，WebSocket 网关降级 · CapFS/OPFS 落盘 |
| 协议 | **LTP/1** — `shared/protocol.js` 单一事实来源，两端字节级一致；NDJSON 文本消息 + 二进制分片帧 |

## 已知说明

- Android APK 为 **debug 签名**，仅用于测试体验；如需上架或正式分发请自行配置 release 签名
- 首次启动若 Windows 防火墙弹窗，请允许「专用网络」访问，否则设备发现会失败
- 端口占用：TCP `53317`、HTTP/WebSocket 网关 `53318`、UDP `53317`（组播发现）
