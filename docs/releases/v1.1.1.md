# 邻传 Nearby Transfer v1.1.1

## 更新说明

- 新增电脑端与 Android 手机端聊天，可在对话中发送和接收文件。
- 修复聊天文件消息、传输进度与文件打开入口的显示问题，并优化手机聊天输入区和底部导航布局。
- 收到新聊天消息时自动打开对应会话；电脑端应用在托盘/后台时会自动唤起。
- 优化文件接收确认弹窗，展示来源设备、IP 地址、端口及文件清单与大小。
- 优化桌面侧栏折叠按钮与收起状态布局。

## 下载

- Windows Setup：直接安装版；未使用公开信任的 Windows 代码签名证书，Windows 可能显示 SmartScreen 提示。
- Android APK：正式签名版本。
- MSIXUPLOAD：供 Microsoft Partner Center 提交；此文件不代表应用已在 Microsoft Store 上架。
